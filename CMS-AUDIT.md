## Deliberately not editable

Each of these is a decision with a reason, not a gap.

| Item                                                   | Why                                                                                                                                     |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| `SITE_URL` and `IS_PRODUCTION_HOST`                    | Gate indexing. A content edit must not be able to deindex the site.                                                                     |
| Robots "index this page" switch                        | Only ever tightening is offered. The build decides indexability.                                                                        |
| Calculator labels, ranges and maths                    | A mislabelled rate field produces a figure a visitor might act on.                                                                      |
| Privacy policy body                                    | Holding page whose prose reads live contact details from settings. Create a `page` document with that slug when the legal text arrives. |
| SMTP, reCAPTCHA secret, Sanity tokens, submission salt | Credentials. Environment only, never in a document anyone with the dataset can read.                                                    |
| reCAPTCHA site key                                     | A matched pair with its secret. Splitting them across the CMS and the deployment lets them drift into a silent failure.                 |
| Colour, type scale, spacing, layout                    | The design system. Named variants are offered where a section genuinely varies.                                                         |
| Footer column count                                    | Three columns is the design. Making it arbitrary would be a redesign.                                                                   |
| Mobile navigation as a separate list                   | It already renders the same nav. A second list that can diverge is a worse CMS.                                                         |
| Carousel arrow and slider `aria-label`s                | Accessibility plumbing for controls with no visible text.                                                                               |
| Honeypot field label                                   | Off-screen anti-spam field. Never seen.                                                                                                 |
| Post and service page templates                        | Not block arrays, so not previewable either. Extracting them is the next step if page-builder control is wanted there.                  |
